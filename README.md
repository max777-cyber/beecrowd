## Como adicionar uma solução automaticamente

Clone o repositório e use o script `novo.sh`:

```bash
# Clone (só na primeira vez)
git clone https://github.com/max777-cyber/beecrowd.git
cd beecrowd

# Torna o script executável (só na primeira vez)
chmod +x novo.sh

# Uso: ./novo.sh <número_do_problema> <linguagem>
./novo.sh 1001 java
./novo.sh 2602 sql
```

Linguagens aceitas: `java`, `python`, `c` e `sql`.

O script cria o arquivo na pasta certa, você cola sua solução, salva e ele já faz **commit + push** automaticamente.
